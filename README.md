# A Rust coding app

This app is an rust coding app for the numworks calculator. It uses the [nadk rust app template](https://github.com/yannis300307/NumworksAppsRust/tree/main) from yannis300307. 

This application should able you to run programs on the numworks calculator without passing through the **python** app. This application is made for rust in particular but it also supports an assembler for those who is brave enough.

This App is still in active development, any contribution is welcome.
